# E-001 RSI 最小改进循环

## 业务结果

让"模型 → 轨迹回流 → 训练集 → 评测 → 新 champion"这条递归循环**第一次可信地跑通**：每轮改进可复现、无污染、有回归地板、可随时回滚。一个季度内完成 ≥3 个完整循环，每轮在目标维度净增益 ≥ +3.0pp，guard 维度零回归，污染事故 0。

## 为什么是跨团队

- 轨迹与训练发生在 MODEL 域，清洗、组装、评测的裁判权在 DATA 域，模型服务的消费方是 AGENT 域——循环的每一步都踩在团队边界上。
- 此前的失败模式：评测口径散落在实验脚本里、"提升"用截图汇报、训练集版本 = 文件名——全部不可审计。本 Epic 是 TriPlane 90 天试点的载体（MODE.md §9）。

## Epic 级验收口径

- 一个完整循环产出 G2/G3/G4/G5 全部门禁证据（含失败循环的完整证据归档）。
- `check.py stats`：契约场景覆盖率 100%，污染审计条目全部机器执行。
- 事故口径：换尺子次数 = 0；训练–评测泄漏 = 0。
